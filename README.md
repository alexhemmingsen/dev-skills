# dev-skills

Agent skills for software development.

## Install

```bash
npx skills@latest add alexhemmingsen/dev-skills
```

To update, run `npx skills@latest update`. To pick up new skills, re-run `add`.

## Skills

| Skill | What it does |
| --- | --- |
| `hello-skills` | Placeholder that confirms the install worked. |

## Related libraries

These are installed from their own repos, not from this one:

```bash
npx skills@latest add mattpocock/skills
npx skills@latest add emilkowalski/skills
```
